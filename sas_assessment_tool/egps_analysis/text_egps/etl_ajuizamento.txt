| Programa   | AJUIZAMENTO                                                                        |
| Autor      | MODELAGEM DE CRÉDITO - BANCO VOTORANTIM                                            |
|            |                                                                                    |
| Objetivo   | O modelo que foi desenvolvido pela área de Modelagem de Crédito e Cobrança tem o   |
|            | objetivo de identificar qual veículo seria rentável para a BV ajuizar.             |
|            |     Para isso, foram utilizadas variáveis comportamentais, cadastrais e            |
|            | relacionadas às características do veículo financiado.                             |
|            |     Além disso, foi desenvolvido um estudo sobre o custo de ajuizamento levando em |
|            | consideração a UF do cliente e o tipo de veículo (Leves ou Motos).                 |
|            |                                                                                    |
|            | O fato de existir muitos veículos ajuizados sem serem retomados trazia altíssimos  |
|            | custos à BV. O modelo estatístico que foi segmentado por produto (Leves e Motos)   |
|            | traz como resultado a probabilidade de retomar ou haver pagamento ou entrega       |
|            | amigável de um determinado veículo, dado que ele foi ajuizado.                     |
|            |     Juntando este resultado com o custo de ajuizar um determinado automóvel foi    |
|            | construída uma matriz e com base nela foi desenvolvida uma política de corte para  |
|            | a decisão de ajuizar ou não o bem financiado.                                      |

PROC SQL;
CREATE TABLE FILTER_CONTRATOSPESSOA AS
	SELECT A.NuCpfCnpj,
		   COUNT(A.NuContrato) AS qtd_rodas,
		   SUM(A.flag_ativo) AS qtd_rodas_aberto
    FROM CONTRATOSRODAS_PORPESSOA AS A
         INNER JOIN CARTEIRALEVES     AS B
		            ON A.NuCpfCnpj = B.NuCpfCnpj
				   AND A.NuContrato <> B.NuContrato
    GROUP BY A.NuCpfCnpj;
QUIT;

PROC SQL NOPRINT;
CONNECT TO SYBASEIQ (&conex_syb.);
    CREATE TABLE TBPARCELA AS SELECT * FROM CONNECTION TO SYBASEIQ
    (

        SELECT a.NuContrato,

        FROM cdcsg.tbparcela as a
        INNER JOIN cdccg.TbContrato b ON a.NuContrato = b.NuContrato AND a.SqContratoFinanceiro = b.SqContratoFinanceiroAtivo
        WHERE a.DtVencimento < &DtProcessamentoCart. AND a.DtUltimoRecebimento < &DtProcessamentoCart.

        INNER JOIN cdccg.TbContrato b ON a.NuContrato = b.NuContrato AND a.SqContratoFinanceiro = b.SqContratoFinanceiroAtivo
