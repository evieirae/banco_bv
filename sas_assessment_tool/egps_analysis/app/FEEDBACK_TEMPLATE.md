# Template de feedback — Painel de Modernização SAS

Use este canvas para sugerir melhorias do app. **Copie o bloco do "Modelo"
abaixo, cole na seção "Envios" e preencha.** Não apague os exemplos nem o
modelo — eles ficam aqui como referência permanente para o próximo a enviar.

**Abas disponíveis:** Resumo · Monitoramento · EGPs · Prioridades · Prontidão ·
Ondas · Linhagem · Histórico · Geral *(para sugestões que não são de uma aba específica,
ex.: tema, navegação, exportação)*.
